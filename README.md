# 🐍 Python Core Foundations: Week 1

**Variables, Data Types, Operators & Input**

</div>

Welcome to **Week 1** of the Python Backend Roadmap! 
This repository contains the foundational concepts of Python programming. The goal of this week is to build a solid base by understanding how to store data, perform operations, and interact with users through input.

---

## 📂 Repository Structure (Topics Covered)

Here is a list of the concepts and projects covered in this week. You can click on the folders to explore the code:

- 🔢 **[1. Variables and Data Types](./1.%20Variables%20and%20Data%20Types)**
  > Learn how to declare variables and understand the basic data types in Python (like Integers, Floats, Strings, and Booleans).

- 🧮 **[2. Arithmetic and Comparison Operators](./2.%20Arithmetic%20and%20comparison%20operators)**
  > Perform math operations (addition, subtraction, etc.) and compare values (greater than, less than, equal to).

- 📝 **[3. Strings - Deep Dive](./3.%20Strings%20-%20Deep%20dive)**
  > Master text manipulation in Python. Learn string methods, formatting, and slicing.

- 🧠 **[4. Logical Operators and Boolean Logic](./4.%20Logical%20Operators%20and%20Boolean%20Logic)**
  > Combine multiple conditions using `and`, `or`, and `not` operators to build logic.

- ⌨️ **[5. Input and Type Conversion](./5.%20Input%20and%20Type%20Conversion)**
  > Take user input from the terminal and convert data types (e.g., changing a string to an integer).

- 🏗️ **[6. Mini Project: Problem Decomposition](./6.%20Mini%20Project%20Day-Problem%20Decomposition)**
  > Learn how to break down a large problem into smaller, manageable pieces before writing code.

- 🚀 **[7. API Rate Limit Calculator](./7.%20API%20Rate%20Limit%20Calculator)**
  > A real-world practical project to calculate API limits based on the concepts learned this week.

## 💻 How to Run the Code

You can easily run any of the Python scripts from your terminal. Just make sure you have Python 3 installed.

Example for running a script:
```bash
python "1. Variables and Data Types/your_script_name.py"
```
*(Make sure to replace `your_script_name.py` with the actual file name you want to run)*
