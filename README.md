## 5. Ввод данных и преобразование типов

### `input_type_conversion.py`

Демонстрирует работу с функцией `input()` и встроенными функциями преобразования типов.

**Ключевые концепции:**

- `input()` — считывает данные от пользователя как строку.
- `int()` — преобразует строку в целое число (например, `"25"` → `25`).
- `float()` — преобразует строку в число с плавающей точкой (например, `"14.5"` → `14.5`).
- `str()` — преобразует число в строку.
- `bool()` — преобразует значение в булев тип (`True` / `False`).
- `type()` — возвращает тип переменной или значения.
- **Неявное (implicit) преобразование** — Python выполняет автоматически (например, `int + float → float`).
- **Явное (explicit) преобразование** — выполняется вручную через `int()`, `float()` и т. д.
- **`ValueError`** — возникает при попытке преобразовать некорректное значение (например, `int("Hello")`).
- `round(number, ndigits)` — округляет число до заданного количества знаков после запятой.

### `practice_input_type_conversion.py`

Практические задачи на применение ввода и преобразования типов.

**Задачи:**

| Задача | Описание |
|---|---|
| **Конвертер размера файла** | Принимает размер файла в МБ, переводит в байты (`MB × 1024 × 1024`). |
| **Калькулятор пропускной способности** | Принимает объём данных (ГБ) и время (сек), вычисляет скорость загрузки в ГБ/с. |
| **Отладка возраста** | Считывает возраст, прибавляет 1 и выводит возраст в следующем году. |
| **Счёт за такси** | Принимает расстояние (км) и цену за км, вычисляет итоговую стоимость поездки. |
