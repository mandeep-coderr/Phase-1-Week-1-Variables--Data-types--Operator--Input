#### `logical_operators_boolean.py` — Основные концепции

- **Логические операторы** (`and`, `or`, `not`):
  - `and` — возвращает `False`, если хотя бы одно условие ложно.
  - `or` — возвращает `True`, если хотя бы одно условие истинно.
  - `not` — инвертирует булево значение.
- **Таблицы истинности** для `and`, `or`, `not` — все комбинации.
- **Короткое замыкание (short-circuit evaluation)** — Python прекращает вычисление, как только результат определён.
- **Truthy / Falsy значения** — `0`, `""`, `None`, `[]`, `{}` считаются ложными (`False`).
  - Проверка через `bool()`.
- **Булева арифметика** — `True` равен `1`, `False` равен `0`:
  - Пример: `True * 200` → `200`.
- **Цепочки сравнений** — `80 <= score <= 89`.
- **Мини-проект: «Умные ворота тематического парка»**:
  - Проверка возраста (пенсионер: 60–100 лет).
  - Доступ в быстрый коридор: `(has_vip or paid_extra) and not is_banned`.
  - Проверка заполненности имени через `bool()`.
  - Расчёт итоговой цены с учётом скидки для пенсионеров.

#### `practice_task_logical_operators_boolean.py` — Практические задания

1. **Доступ к системе** — комбинация `or` и `not`:
   - Доступ разрешён, если пользователь активен или является администратором, и не заблокирован.
   - `(is_admin or is_active) and not is_banned`

2. **Валидация сетевого порта** — цепочка сравнений:
   - Порт считается валидным при `0 < port <= 65535`.
   - Входное значение преобразуется из строки в `int` перед проверкой.

3. **Truthy / Falsy поведение** — проверка через `bool()`:
   - `""` → `False`
   - `0` → `False`
   - `"config"` → `True`
