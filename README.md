## 3. Строки — глубокое погружение (`3. Strings - Deep dive/`)

### `Strings.py`

Демонстрирует ключевые операции со строками в Python.

| Тема | Описание |
|---|---|
| **Индексация** | Доступ к символу по позиции: `Fruit[1]` |
| **Отрицательная индексация** | Доступ с конца строки: `Fruit[-1]` |
| **Срезы (Slicing)** | `s[start:end:step]` — выборка подстроки |
| **Магический разворот** | `word[::-1]` — разворот строки |
| **`len()`** | Подсчёт всех символов, включая пробелы |
| **`.lower()` / `.upper()`** | Приведение к нижнему / верхнему регистру |
| **`.title()`** | Первая буква каждого слова — заглавная |
| **`.capitalize()`** | Первая буква строки — заглавная |
| **`.strip()` / `.lstrip()` / `.rstrip()`** | Удаление пробелов с обеих / левой / правой стороны |
| **`.replace()`** | Замена подстроки |
| **`.split()`** | Разбивка строки на список слов |
| **`.join()`** | Склейка списка слов в строку |
| **Конкатенация `+`** | Объединение строк: `word1 + " " + word2` |
| **Повторение `*`** | Копирование строки: `laugh * 20` |
| **f-строки** | Современный способ вставки переменных в текст: `f"Hello {name}"` |
| **Оператор `in`** | Проверка наличия подстроки: возвращает `True` / `False` |

### `practice_task_on_strings.py`

Практические задания на закрепление материала.

- Извлечение ID и имени из строки `"Agent 007 - James Bond"` с помощью срезов.
- Вывод символов через один (`s[::2]`) и в обратном порядке через один (`s[::-2]`).
- Цепочка методов: `name.strip().title()` — очистка пробелов и форматирование.
