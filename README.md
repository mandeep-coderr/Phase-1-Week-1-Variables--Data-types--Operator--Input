## 6. Мини-проект — Декомпозиция задачи

**Файл:** `6. Mini Project Day-Problem Decomposition/Mini_project_for_day.py`

Программа содержит два мини-проекта:

### 1. Калькулятор возраста

- Запрашивает у пользователя год рождения (`input`).
- Вычисляет текущий возраст: `2026 - год_рождения`.
- Выводит результат в консоль.

**Пример запуска:**
```
What is your Birth year? 2000
Your age is 26
```

### 2. Расчёт стоимости товара с налогом

- Цена товара (черника): `1100`.
- Налог: `18%` от цены.
- Итоговая цена: цена + налог.
- Проверяет, является ли товар дорогим (`total_price >= 1200`).
- Выводит итоговую цену и результат проверки.

**Пример вывода:**
```
1298.0
True, This fruit is expensive
```
